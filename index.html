OpenWeb Linux en la web

Un shell completo inspirado en Alpine Linux (busybox, apk y OpenRC simulados) que corre entero en tu navegador. Todo lo que crees se guarda aquí mismo, sin cuenta ni servidor.

Es una simulación completa, no una VM: los comandos, paquetes y servicios se ejecutan con JavaScript en esta misma página. No necesitas HTTPS, no hay descargas y el sistema arranca al instante.

  1. Escribe help para ver todos los comandos. Navega con ls, cd y cat; el sistema de archivos vive en /root, /etc, /tmp…
  2. Instala paquetes simulados con apk add cowsay, apk add neofetch o apk add figlet: esos paquetes añaden comandos reales al sistema.
  3. Gestiona servicios estilo OpenRC con rc-status, rc-service sshd start y rc-update add sshd default.
  4. Encadena comandos con |, guarda salidas con > o >> y lee archivos con <.
  5. Tu sistema se guarda solo en este navegador. Usa Guardar para descargarlo como JSON o Abrir para restaurarlo en otro dispositivo.

apk · paquetes simulados

El gestor de paquetes estilo Alpine de este shell. Pulsa Copiar y pégalo en la terminal.

Servicios (OpenRC simulado)

Hay servicios de base (networking, crond) y otros que aparecen al instalar su paquete: openssh-server, nginx y ntp.

rc-status
rc-service sshd status
rc-update add sshd default

Instalación simulada

setup-alpine

Conservar el sistema

El sistema se guarda solo en este navegador. Descarga también una copia si quieres moverla a otro dispositivo.

El archivo JSON incluye archivos, paquetes instalados, servicios y el historial de cada terminal. Es un respaldo pequeño: puedes editarlo a mano.

Restaurar sistema

Abre un respaldo .json exportado desde este mismo sitio (también se aceptan respaldos antiguos de la versión 1).

La copia local no se comparte entre navegadores ni dispositivos; para moverla, descarga el JSON y ábrelo desde el otro navegador.
