Alpine Linux en la web

OpenWeb arranca Alpine Linux, una distribución ligera para sistemas virtualizados, dentro de una máquina x86.

Alpine se inicia como un sistema live: la imagen Alpine virt x86 incluye un sistema mínimo y usa 256 MiB de RAM. Inicia como root; ejecuta setup-alpine para configurar la red y, si quieres conservar una instalación en el disco virtual de 512 MiB, sigue las indicaciones para instalar en /dev/sda. Guarda el estado de v86 antes de cerrar o recargar.

La imagen virt ocupa unos 49 MiB. Incluye controladores pensados para máquinas virtuales y usa virtio en v86. La descarga de paquetes al configurar Alpine depende de tu conexión y del mirror seleccionado.

  1. Pulsa Arrancar Alpine. En la consola de inicio, escribe root para entrar. Ya puedes usar el sistema live; ejecuta setup-alpine si quieres instalarlo al disco.
  2. En la configuración, elige eth0 y una mirror Alpine cercana. La red pasa por un relay público; no uses contraseñas ni datos sensibles durante esa conexión.
  3. La sesión live funciona en memoria. El instalador configura Alpine en el disco; ambas cosas se pierden al cerrar o recargar si no guardas el estado de v86.
  4. Usa Guardar para exportar el estado completo de v86 (.bin) y Abrir para restaurarlo. El archivo puede ser muy grande.
  5. En móvil, pulsa ⌨ Teclado para escribir y usar teclas especiales en Alpine.

apk · paquetes Alpine

Escribe estos comandos en la consola Alpine como root. Alpine usa apk en lugar de apt.

apk update
apk upgrade
apk add <paquete>
apk info
apk search <paquete>

Servicios de Alpine (OpenRC)

Ejecuta los comandos en la consola Alpine como root. Alpine usa OpenRC, no systemd.

rc-status
rc-service <servicio> status
rc-update add <servicio> default
rc-update del <servicio> default

Instalación al disco

El asistente setup-alpine configura la instalación y el arranque. Para instalar manualmente el sistema en el disco:

setup-disk -m sys /dev/sda

Conservar el entorno

Elige cómo guardar tus cambios. El almacenamiento local solo está disponible en este navegador.

Los estados de VM pueden ocupar mucho espacio. Si el navegador no tiene cuota suficiente, usa la descarga del archivo .bin.

Restaurar entorno

Restaura la última copia de este navegador o abre un archivo de respaldo.

La copia local no se comparte entre navegadores ni dispositivos. Para moverla, descarga el archivo .bin y ábrelo desde el otro navegador.
