Setup de Debian en la web

Para tener una terminal Debian real y ejecutar apt, la página necesita arrancar una máquina virtual x86 dentro del navegador.

Instalador de red, no sistema live: al arrancar se ejecuta el instalador Debian 12 i386 con 512 MiB de RAM y un disco virtual temporal de 1 GiB para pruebas de instalación mínima. Debes completar la instalación antes de tener un Debian normal con apt; el disco se pierde al cerrar o recargar salvo que guardes el estado.

  1. Pulsa Arrancar Debian, haz clic dentro de la pantalla virtual para enviarle el teclado y sigue el instalador; selecciona la unidad virtual para instalar.
  2. Para descargar paquetes, el instalador usa un relay público de red y los repositorios Debian. No uses contraseñas ni datos sensibles durante esa conexión.
  3. Al terminar, el sistema instalado y tus cambios siguen en memoria hasta que cierres o recargues la página.
  4. Usa Guardar para exportar el estado completo de v86 (.bin) y Abrir para restaurarlo. El archivo puede ser muy grande.

apt · paquetes Debian

Cuando termine la instalación y estés en la terminal Debian, puedes usar estos comandos. La ISO incluida abre el instalador de red, no un escritorio live.

sudo apt update
sudo apt upgrade
sudo apt install <paquete>
apt list --installed
