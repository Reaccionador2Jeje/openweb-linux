

# OpenWeb Linux

OpenWeb Linux is a complete Linux distribution designed to run directly in the browser. It boots a real, minimal 32-bit x86 Linux system inside the web page using the v86 JavaScript emulator, providing a portable Linux environment without needing to install a system on your machine.

## Overview

OpenWeb Linux is a browser-based Linux distribution focused on accessibility, portability, and usability. Instead of requiring a traditional installation, it runs inside a web environment while still behaving like a real Linux system.

## Features

- Runs a full Linux system in the browser
- Built on the v86 emulator
- Includes its own package manager
- Designed to be complete and self-contained
- Does not require an ISO download to boot
- No third-party asset host is needed for the default kernel and emulator files
- Lightweight and portable enough to use from nearly any browser

## How it works

OpenWeb Linux serves the default kernel and emulator assets directly from the project itself. The browser loads the Linux environment through the v86 emulator, which emulates an x86 machine and boots the operating system inside the page.

This approach makes OpenWeb Linux more than a simple browser demo: it is a full Linux distribution that runs in the web and preserves the experience of using a real system.

## Package Manager

OpenWeb Linux includes its own package management system, allowing software to be installed and managed inside the running environment. This makes it a more complete and functional Linux distribution rather than a lightweight showcase.

## Why it stands out

By combining a real Linux system with browser execution, OpenWeb Linux offers a unique experience: an operating system that is complete, portable, and easy to launch from the web.

## Project Status

OpenWeb Linux is a lightweight, experimental, and highly portable Linux distribution designed to run directly in the browser using the v86 emulator.

## Repository

This repository contains the project assets and configuration required to boot and run OpenWeb Linux in a web browser.
