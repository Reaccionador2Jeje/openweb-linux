# AtDev Billing compatibility — OpenWeb Linux

**Status:** proposal only. OpenWeb Linux is a browser-based local simulation and remains free to use without an account.

## Hybrid model

Keep the shell simulator, command execution, local filesystem, package simulation, and local backups free. Do not require registration or a subscription for the core experience. Optional monetization should be limited to voluntary support or cosmetic themes that do not change command behavior, data privacy, or core access.

## Proposed tiers (CLP/month; exploratory)

| Plan | Reference price | Scope |
| --- | ---: | --- |
| Community | $0 | Full local browser simulator |
| Supporter | Voluntary | Optional contribution and acknowledgment |
| Themes Plus | $490 | Future optional visual themes, if implemented |

The simulator currently runs locally in the browser. Do not claim cloud hosting, real Linux virtualization, or managed infrastructure as a paid benefit unless those capabilities are genuinely built.

No checkout is active. Any future payment feature requires adult account-owner review of provider eligibility and legal/tax obligations.
