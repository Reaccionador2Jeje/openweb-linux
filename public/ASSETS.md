# Bundled assets

- `images/openweb-linux.svg` is the original OpenWeb Linux project logo and browser-tab icon.

The site no longer bundles any third-party runtime. Previous releases shipped v86 (BSD-2-Clause), SeaBIOS/VGA BIOS files (LGPL-2.1) and official Alpine Linux ISO images; those were removed when the VM flow was retired in favour of the fully simulated JavaScript shell. The git history still contains them.
